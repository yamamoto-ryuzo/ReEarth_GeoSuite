QGIS連携（qgis: / theme:）

QGIS プラグイン geo_webview が出力する .kasc プロジェクト （kasugai_canvas.kasc + DATA/）を、インスペクタの qgis: 行で取り込みます。.kasc はレイヤー・スタイル・カメラ・ テーマを列挙する固定名の目次ファイルです。

指定方法（2形態）

指定動作用途
qgis: <解凍済み out_dir のURL> フォルダURL → <url>/kasugai_canvas.kasc を自動解決。DATA/… はフォルダ基準で逐次 fetch（巨大データ向け） 生フォルダ参照（geo_webview :8089 配信＝常に最新）
qgis: <…/xxx.zip> ブラウザ内で ZIP 解凍（fflate）→ .kasc 解釈 → DATA/… は kasczip://<id>/<path> メンバ参照 搬送・配布用スナップショット（無データ〜小データ向け）

※ いずれも project.json があれば表示タイトルに利用。公開URLで使うには .kasc＋DATA/ の HTTP(S) 静的配信と CORS 許可が必要です。

マップテーマ（v22.6.0〜）

QGIS のマップテーマ（可視レイヤー集合＋テーマ別名前付きスタイル）が theme: 行としてエクスポートされます（geo_webview 4.6.0〜）。

  • theme: <テーマ名> | <タイトル> | <タイトル>;style=DATA/<slug>__<theme>.qml
  • 取り込み時に theme: 行がパースされ、タブバーのテーマセレクトで 可視レイヤー集合を切替可能（* は全表示）
  • ;style= 指定のあるレイヤーはテーマ別 .qml へ外観を差替 （ZIP 内では kasczip:// メンバ参照に書き換え済み）
  • AI ツール listThemes / applyKascTheme で AI チャットからも テーマ一覧・切替が可能

認識される出力物

出力物扱い
kasugai_canvas.kasc展開して行パース（レイヤー・base:・cam:・theme:）
DATA/<slug>.qmlstyle= 参照経由で読み込み・適用
DATA/<slug>.<ext>（.gpkg/.geojson/.fgb/.parquet 等）レイヤー行参照経由で読み込み
DATA/<slug>/（XYZツリー・3D Tiles）参照経由で利用
DATA/<slug>__<theme>.qmlテーマ適用時の差替スタイル
DATA/<slug>_<asset>.svg/png.qml 内シンボル画像参照
bookmarks.xmlブックマークプリセット（kasczip メンバとして読込可）

Canvas 側の受け方（参考）

KASUGAI Canvas 本体は同じパッケージを ?kasc=<zip URL> で直接取り込みます （ブラウザ内解凍＋kasczip:// メンバ参照、geo_suite と同構造）。

詳細は KASUGAI Canvas 側の「QGIS連携の利用方法」を参照。
